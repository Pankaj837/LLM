# Data

This folder is **empty in the repository on purpose** — no dataset is committed to git (see `.gitignore`:
`data/`, `runs/`, `*.pt`, `*.bin`, `*.tok`). Everything here is either generated by a script from an external
source, or synthesised in memory by test code. Nothing here needs to be "found" — it is reproduced by running
the commands below.

## Real datasets (external, not part of this repo)

| Dataset | Source file (outside the repo) | Prepared into | Schema / size | Regenerate |
|---|---|---|---|---|
| Biology | `Biology Dataset.zip` (539 MB; 7 gzipped JSONL shards: pes2o, pmc_oa, libretexts, qbio, qbio_full, bhl, gutenberg) | `data/bio/{train,val}.bin`, `vocab.tok`, `manifest.json` | 5.39M train / 274k val tokens, vocab 8000; full profile and per-record JSON schema in `docs/BIOLOGY_SMOKE_TEST.md` | `python scripts/prepare_biology.py --zip "Biology Dataset.zip" --out data/bio` |
| Earth & Environment | `Earth and Environment Processed Dataset.zip` (24 MB; pre-tokenized by another contributor) | `data/earth/{train,val}.bin`, `tokenizer.json`, `manifest.json` | 3.54M train / 394k val tokens, vocab 8192; the delivered `.bin` files use their **own, incompatible** 24-byte header (`GNRP`, not this repo's 36-byte `TOK1`) — see `docs/EARTH_ENVIRONMENT_SMOKE_TEST.md` and finding F-29 | `python scripts/prepare_earth.py --zip "Earth and Environment Processed Dataset.zip" --out data/earth` |

Both source zips are large binary files and are kept **outside** this repository (a sibling of the repo root in
this delivery); point `--zip` at wherever they actually live on your machine.

## Synthetic data (generated in memory, no files, fully reproducible)

| What | Where it's defined | Size | Determinism |
|---|---|---|---|
| Conditional-reward preference pairs | `src/llm/reward/preferences.py` (`build_dataset`) | 240 pairs over 20 topics, 4 response variants each | `seed` argument; `seed=0` used throughout the docs |
| Stand-in BPE vocabulary | `src/llm/bpe_trainer.py` + `tests/helpers.py::write_standin_vocab` | 1722 tokens (reward corpus) or configurable | Deterministic given the input text and `vocab_size` |
| Small-model fixtures | `tests/helpers.py::small_lm_config` | ~6-layer, d=64 toy transformer | Fixed dataclass, no randomness until weights are initialised (then `torch.manual_seed`) |

None of these are the team's real C++ tokenizer vocabulary — see `docs/REVIEW_FINDINGS.md` F-22/F-29 for what is
still outstanding on that front.

## Checkpoints

Also not committed (`*.pt` is gitignored). `scripts/make_scaffold_checkpoint.py` produces a small, explicitly
`untrained=True`-flagged checkpoint for wiring tests; `runs/*/ckpt_last.pt` from a real training run (biology or
earth) is the nearest thing to a "trained" artifact currently available — see `docs/REVIEW_FINDINGS.md` F-01 for
why the originally delivered `pretrain_model.pt` does not count as one.
